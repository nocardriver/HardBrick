# compass 应用层（QMC5883P 罗盘）

25 Hz 采样 → 硬磁标定 → 航向角，快照用互斥量保护，供显示/上位机读取。

## 快速上手

```c
/* main.c USER CODE 2（内核启动前） */
compass_hw_init();     /* 配置传感器：Normal / ODR 200 Hz(有效 50 Hz) / OSR2=4 / ±8 G */

/* tx_application_define()（内核启动后） */
compass_init();        /* 建互斥量 + 25 Hz 采集线程，优先级 8（最低） */

/* 任意线程 */
compass_snapshot_t s;
compass_get(&s);       /* s.heading_deg10 / s.field_mg / s.calibrated ... */
```

## 标定：画 8 字

拿在手里画 8 字，同时让板子前倾、后仰、左右侧翻（每个方向翻过 45°），持续 15~20 秒。
**不需要保持水平**，但姿态要在三维上真的变化。成功后 RTT 会打印 `cal=1`，标定结果
一直保留（掉电才丢）。

门限（任一不过则保持上一次成功的标定）：

| 指标 | 门限 | 含义 |
|---|---|---|
| `spr` | ≥150 (‰) | 样本协方差最小/最大特征值之比，衡量三维覆盖；只在一个平面转时会很小 |
| `cov` | ≥10 (/12) | xy 投影覆盖的 30° 扇区数，航向只用 x/y，必须转遍平面 |
| `r` | 250~750 mG | 拟合球半径 = 当地总场强；上海约 490 |
| `rms` | ≤8 mG | 径向残差，软磁强或有外部干扰时会变大 |

诊断量每秒无论成败都会打印，看 `[MAG] hdg=... cal=... off=... r=... rms=... spr=... cov=...`。

## 实测（HardBrick 本板）

- 画 8 字一次即成功：`off=(2, 148, 4) mG`、`r=414 mG`、`spr=302‰`、`cov=12/12`；
- 与手机指南针同方位对比，最大偏差 <10°；
- 修 OSR2=4 后 z 轴静止标准差 10+ mG → 2.1 mG（参考 PX4 #26350）。

## 已知误差来源

1. **软磁未补偿**：只解硬磁（球拟合），各轴增益不等时会产生"0°/180° 对得上、
   90°/270° 偏得多"的误差；`|B|` 实测 420 mG 比理论 490 低 14% 也指向这一点。
   要更准需要完整椭球拟合（解 `A` 矩阵）+ 矩阵平方根。
2. **倾斜未补偿**：航向只用 x/y，板子不平时会有 10~20° 误差；需要加速度计。
3. **磁偏角**：`hdg` 是相对**磁北**的方位，上海磁偏角约 -5.5°，即
   `hdg ≈ 手机(真北) + 5.5°`。安装方向不同再用 `compass_set_heading_offset()` 补。

## 两个容易踩的坑

- 线程栈必须 ≥3072 B：`compass_fit`（920 B）+ `eig3_sym`（288）+ `det3`（168）+
  线程帧（280）≈1.7 KB，栈小了第一次完整拟合就 HardFault。
- 传感器 +Z 朝下（实测平放时 z≈+350 mG，而地磁竖直分量向下），所以航向角是
  `atan2(-y, x)`；换板子/换安装方向时改 `COMPASS_Y_INVERT`。
